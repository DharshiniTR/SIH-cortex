# Build a Full-Stack Tamil Nadu e-Sevai Clone

Build a **single full-stack website** that closely clones the **4 uploaded screenshots** of the Tamil Nadu e-Sevai / e-District portals.

### Tech Stack

* Frontend: **React + Vite**
* Backend: **Python FastAPI**
* Database: **SQLite + SQLAlchemy**
* API calls: **Axios**
* React Router for navigation

### UI

Use the uploaded screenshots as the **exact visual reference**.

Recreate:

* Tamil Nadu Government header and TNeGA/e-Sevai branding
* Green left sidebar
* Blue navigation bars
* Services page
* Department-wise and service-wise lists
* Search, alphabet filter and pagination
* Service details page
* Citizen e-District page
* Application form
* Application status page
* Certificate download page
* Saved Applications
* Returned Applications
* Reprint Receipt
* Login page

Keep the **same colors, layout, spacing, fonts, buttons and overall legacy government-portal appearance**. Do not redesign it into a modern SaaS dashboard.

### Backend

Connect the React frontend to FastAPI.

Create APIs for:

```text
POST /api/auth/login
GET  /api/departments
GET  /api/services
GET  /api/services/{id}
POST /api/applications
GET  /api/applications/{id}
PUT  /api/applications/{id}
GET  /api/applications/{id}/certificate
GET  /api/applications/{id}/receipt
```

Store users, departments, services and applications in SQLite.

Create realistic sample services such as:

Make all buttons and navigation actually work.

### Important

Do **not** create a static frontend or fake buttons.

The frontend must communicate with the FastAPI backend and use database data.

Generate the complete project with a clean structure and make sure it runs in Replit with:

```text
Frontend: React/Vite
Backend: FastAPI
Database: SQLite
```

The final result should look like a **single unified Tamil Nadu e-Sevai/e-District portal based on the 4 uploaded screenshots**.
